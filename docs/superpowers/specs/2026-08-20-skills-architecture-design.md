## 2. Interactive Synaptic Visuals & Motion

### Dynamic Synaptic Forward-Pass (SVG Canvas)
- An SVG canvas connects the layers from left to right with delicate bezier curves (`stroke: var(--border-color)`, `opacity: 0.25` at rest).
- **Hover Activation Signal**:
  - Hovering a node (e.g. `Python` in L01) illuminates connected paths through `PyTorch` (L02), `DGX Systems` (L03), to `Advanced RAG` (L04).
  - High-contrast activation pulse flows forward along the synaptic path.

### Interactive Neuron Nodes
- Precision geometric pill with monochrome SVG tech icon + exact item label.
- Hover lift: `transform: translateY(-2px) scale(1.05)` with crisp high-contrast border and background shift.

### Layer Telemetry Headers
- Monospace layer badges in Geist Mono:
  - `L01 // LANGUAGES & BACKEND [ 09 NODES ]`
  - `L02 // FRAMEWORKS & RETRIEVAL [ 10 NODES ]`
  - `L03 // CLOUD & INFRASTRUCTURE [ 06 NODES ]`
  - `L04 // APPLIED AI & AGENTS [ 07 NODES ]`
